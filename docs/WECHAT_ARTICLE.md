# CTF Agent：基于LangGraph的自主渗透测试智能体

> 团队原创，转载请注明出处

---

## 项目背景

随着网络安全攻防演练和CTF竞赛的普及，自动化渗透测试工具的需求日益增长。传统工具往往依赖人工操作，难以应对复杂的多层网络环境。我们团队基于大语言模型和图编排技术，开发了CTF Agent——一个能够自主完成渗透测试任务的智能体系统。

---

## 核心架构

CTF Agent采用**LangGraph**作为核心编排框架，将渗透测试流程抽象为可组合的有向图结构，实现了灵活的任务调度和状态管理。

### 架构亮点

- **图节点化设计**：将侦察、分析、攻击、验证等环节抽象为独立节点，支持动态路由
- **状态持久化**：完整的任务状态管理，支持断点续传和错误恢复
- **模块化工具链**：集成70+渗透测试工具，按需动态加载
- **RAG知识增强**：结合向量数据库检索历史Writeup，提升攻击成功率

---

## 功能特性

### 1. AI战略思维

系统引入**战略上下文（StrategicContext）**机制，让AI具备类似渗透测试人员的全局视野：

- 空间认知：识别当前处于Web层、内网层还是云环境
- 攻击链规划：自动分解目标为多步骤攻击路径
- 障碍感知：动态识别阻碍因素并生成备选方案

![攻击链可视化](./images/attack_chain.png)
*攻击链可视化展示*

### 2. 四大赛区覆盖

| 赛区 | 覆盖场景 | 核心能力 |
|------|----------|----------|
| 第一赛区 | Web安全 | SQL注入、XSS、SSTI、SSRF等漏洞自动化挖掘 |
| 第二赛区 | CVE/云/AI | CVE漏洞利用、云环境渗透、AI应用攻击 |
| 第三赛区 | 多层网络 | 内网探测、横向移动、隧道代理 |
| 第四赛区 | 内网渗透 | AD域攻击、凭据窃取、权限维持 |

### 3. 智能模块管理

系统根据当前任务场景动态加载所需模块，实现内存资源优化：

- Web模式：加载SQLMap、Nuclei、Dalfox等Web工具
- 内网模式：加载Mimikatz、BloodHound、CrackMapExec等内网工具
- 模式切换响应时间 < 2秒

## 技术实现

### 工具集成

项目集成了行业主流的渗透测试工具：

```
├── Web扫描：Nuclei、Xray、SQLMap、FFUF
├── 内网渗透：Mimikatz、BloodHound、CrackMapExec
├── AD域攻击：ZeroLogon、Shadow Credentials、AD CS Abuse
├── 云安全：Cloud Scanner、Kubernetes Attacker
└── 通用工具：Python执行器、编码解码器
```

### 攻击图模型

针对内网多层网络环境，系统实现了基于Dijkstra算法的**攻击图模型**：

- 自动构建主机节点和攻击路径
- 计算最优攻击路径
- 识别关键攻击节点

![攻击图模型](./images/attack_graph.png)
*内网攻击路径规划*

### 提示词工程

针对渗透测试场景，设计了三层提示词体系：

1. **分析层**：场景联想、漏洞优先级排序
2. **执行层**：攻击决策推理、预期结果预判
3. **验证层**：进度评估、策略调整建议

## 部署方式

项目支持Docker一键部署：

```bash
docker build -t ctf-agent .
docker run -d -p 54565:54565 ctf-agent
```

访问 `http://localhost:54565/fisher_ctf_agent/monitor` 即可使用Web控制台。
