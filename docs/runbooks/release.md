# Release Runbook

## 目标

把“发布”从口头动作改成可执行、可回滚、可审计的流程。

---

## 角色

- Agent：默认无发布权限
- Maintainer：可以整理分支、准备发布 PR
- Release Operator：执行最终发布

---

## 发布前检查

1. 目标改动已经通过 PR 合并
2. PR 已包含文档更新
3. 发布说明已准备
4. 已执行至少以下命令：

```bash
make lint
make test
make security
```

如果某一步失败，必须在发布记录中显式说明，不允许默认跳过。

---

## 标准流程

1. 从受保护主分支切出发布准备分支
2. 更新版本号、发布说明、必要的 runbook
3. 再跑一轮统一校验
4. 打 tag
5. 推送 tag 与发布分支
6. 由 Release Operator 执行目标环境发布

---

## 发布记录最少字段

- 版本号 / tag
- 提交哈希
- 关联 PR
- 执行人
- 校验命令与结果
- 回滚点

---

## 注意

- Agent 默认不能直连生产环境
- 生产发布必须由具备发布权限的角色执行
