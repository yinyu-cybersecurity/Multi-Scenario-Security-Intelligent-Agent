## 1. 工具系统架构总览

### 1.1 核心设计理念

Claude Code 的工具系统采用了**工厂模式 + 约定优于配置**的设计:

```
Tool Definition → buildTool() → Complete Tool → Registration → Execution
     ↓                ↓              ↓              ↓           ↓
  Zod Schema     默认值填充      类型安全实例    tools.ts     query.ts
```

**关键设计原则**:

1. **类型安全**: 使用 Zod schema 进行运行时验证
2. **默认值安全**: 工厂函数提供安全的默认值
3. **权限分离**: 权限检查与执行分离
4. **并发控制**: 通过 `isConcurrencySafe` 标记并发安全工具
5. **延迟加载**: 支持工具延迟加载减少 prompt 大小

## 3. buildTool 工厂函数

### 3.1 工厂函数设计

`buildTool` 是创建工具的核心工厂函数，它提供**安全的默认值**，确保工具定义完整。

```typescript
/**
 * 可默认的方法 - buildTool 会填充安全默认值
 */
type DefaultableToolKeys =
  | 'isEnabled'         // 是否启用
  | 'isConcurrencySafe' // 是否并发安全
  | 'isReadOnly'        // 是否只读
  | 'isDestructive'     // 是否破坏性
  | 'checkPermissions'  // 权限检查
  | 'toAutoClassifierInput'  // 自动分类器输入
  | 'userFacingName'    // 用户友好名称

/**
 * 工具定义 - 这些方法可选
 */
export type ToolDef<Input, Output, P> = 
  Omit<Tool<Input, Output, P>, DefaultableToolKeys> &
  Partial<Pick<Tool<Input, Output, P>, DefaultableToolKeys>>
```

### 3.2 默认值定义

```typescript
const TOOL_DEFAULTS = {
  // 默认启用
  isEnabled: () => true,
  
  // 默认非并发安全 (保守策略)
  isConcurrencySafe: (_input?: unknown) => false,
  
  // 默认非只读 (保守策略)
  isReadOnly: (_input?: unknown) => false,
  
  // 默认非破坏性
  isDestructive: (_input?: unknown) => false,
  
  // 默认允许 (委托给通用权限系统)
  checkPermissions: (
    input: { [key: string]: unknown },
    _ctx?: ToolUseContext,
  ): Promise<PermissionResult> =>
    Promise.resolve({ behavior: 'allow', updatedInput: input }),
  
  // 默认跳过分类器
  toAutoClassifierInput: (_input?: unknown) => '',
  
  // 默认返回空字符串 (会被 buildTool 覆盖为工具名)
  userFacingName: (_input?: unknown) => '',
}
```

### 3.3 buildTool 实现

```typescript
export function buildTool<D extends AnyToolDef>(def: D): BuiltTool<D> {
  return {
    // 先应用默认值
    ...TOOL_DEFAULTS,
    
    // 覆盖 userFacingName 默认值为工具名
    userFacingName: () => def.name,
    
    // 应用用户定义
    ...def,
  } as BuiltTool<D>
}
```

### 3.4 使用示例

```typescript
// GlobTool - 文件匹配工具
export const GlobTool = buildTool({
  name: GLOB_TOOL_NAME,
  searchHint: 'find files by name pattern or wildcard',
  maxResultSizeChars: 100_000,
  
  // Schema 定义
  inputSchema: lazySchema(() => z.strictObject({
    pattern: z.string().describe('The glob pattern to match files against'),
    path: z.string().optional().describe('The directory to search in'),
  })),
  
  outputSchema: lazySchema(() => z.object({
    durationMs: z.number(),
    numFiles: z.number(),
    filenames: z.array(z.string()),
    truncated: z.boolean(),
  })),
  
  // 覆盖默认值
  isConcurrencySafe() {
    return true  // Glob 是并发安全的
  },
  
  isReadOnly() {
    return true  // Glob 是只读的
  },
  
  // 核心执行逻辑
  async call({ pattern, path }, context, canUseTool, parentMessage, onProgress) {
    const cwd = path ? expandPath(path) : getCwd()
    const result = await glob(pattern, { cwd })
    return {
      data: {
        durationMs: result.durationMs,
        numFiles: result.matches.length,
        filenames: result.matches,
        truncated: result.truncated,
      }
    }
  },
  
  // 权限检查
  async checkPermissions({ path }, context) {
    return checkReadPermissionForTool(context, path)
  },
  
  // 其他方法...
  userFacingName: () => 'Glob',
  isSearchOrReadCommand: () => ({ isSearch: true, isRead: false }),
})
```

### 4.2 getTools - 根据权限上下文过滤工具

```typescript
export const getTools = (permissionContext: ToolPermissionContext): Tools => {
  // 简单模式: 只返回 Bash, Read, Edit
  if (isEnvTruthy(process.env.CLAUDE_CODE_SIMPLE)) {
    const simpleTools: Tool[] = [BashTool, FileReadTool, FileEditTool]
    
    // 协调者模式下添加额外工具
    if (isCoordinatorMode()) {
      simpleTools.push(AgentTool, TaskStopTool, getSendMessageTool())
    }
    
    return filterToolsByDenyRules(simpleTools, permissionContext)
  }

  // 获取所有基础工具
  const tools = getAllBaseTools().filter(tool => !specialTools.has(tool.name))

  // 过滤 deny 规则
  let allowedTools = filterToolsByDenyRules(tools, permissionContext)

  // REPL 模式处理
  if (isReplModeEnabled()) {
    const replEnabled = allowedTools.some(tool =>
      toolMatchesName(tool, REPL_TOOL_NAME),
    )
    if (replEnabled) {
      allowedTools = allowedTools.filter(
        tool => !REPL_ONLY_TOOLS.has(tool.name),
      )
    }
  }

  // 过滤未启用的工具
  const isEnabled = allowedTools.map(_ => _.isEnabled())
  return allowedTools.filter((_, i) => isEnabled[i])
}
```

### 4.3 filterToolsByDenyRules - 权限规则过滤

```typescript
export function filterToolsByDenyRules<T extends {
  name: string
  mcpInfo?: { serverName: string; toolName: string }
}>(tools: readonly T[], permissionContext: ToolPermissionContext): T[] {
  return tools.filter(tool => !getDenyRuleForTool(permissionContext, tool))
}
```

### 4.4 assembleToolPool - 组装完整工具池

```typescript
export function assembleToolPool(
  permissionContext: ToolPermissionContext,
  mcpTools: Tools,
): Tools {
  // 1. 获取内置工具
  const builtInTools = getTools(permissionContext)

  // 2. 过滤 MCP 工具
  const allowedMcpTools = filterToolsByDenyRules(mcpTools, permissionContext)

  // 3. 按名称排序 (Prompt Cache 稳定性)
  const byName = (a: Tool, b: Tool) => a.name.localeCompare(b.name)
  
  // 4. 合并并去重 (内置工具优先)
  return uniqBy(
    [...builtInTools].sort(byName).concat(allowedMcpTools.sort(byName)),
    'name',
  )
}
```

### 5.1 BashTool - Shell 执行工具

```typescript
const fullInputSchema = lazySchema(() => z.strictObject({
  command: z.string().describe('The command to execute'),
  timeout: z.number().optional().describe(`Optional timeout in milliseconds`),
  description: z.string().optional().describe('Clear, concise description'),

// 工具定义
export const BashTool = buildTool({
  name: BASH_TOOL_NAME,
  maxResultSizeChars: 2_000_000,  // 2MB
  
  async call({ command, timeout, description, run_in_background, ... }) {
    // 1. 解析命令
    const parsed = parseForSecurity(command)
    
    // 2. 检查沙箱
    const useSandbox = shouldUseSandbox(command, context)
    
    // 3. 执行命令
    if (run_in_background) {
      // 后台执行
      const taskId = await spawnShellTask({ command, ... })
      return { data: { taskId, status: 'background' } }
    } else {
      // 前台执行
      const result = await exec(command, { timeout, sandbox: useSandbox })
      return { data: { stdout: result.stdout, stderr: result.stderr, exitCode: result.exitCode } }
    }
  },
  
  // 搜索/读命令检测
  isSearchOrReadCommand(input) {
    return isSearchOrReadBashCommand(input.command)
  },
  
  // 权限检查
  async checkPermissions(input, context) {
    return bashToolHasPermission(context, input.command)
  },
  
  // 非并发安全
  isConcurrencySafe: () => false,
  
  // 非只读
  isReadOnly: () => false,
})
```

**关键特性**:

1. **沙箱支持**: 通过 `dangerouslyDisableSandbox` 控制沙箱
2. **后台执行**: `run_in_background` 支持后台任务
3. **命令分类**: 区分搜索/读/列表命令用于 UI 折叠
4. **安全解析**: AST 级别安全检查

```typescript
  name: FILE_READ_TOOL_NAME,
  maxResultSizeChars: Infinity,  // 永不持久化到磁盘
  
  inputSchema: lazySchema(() => z.strictObject({
    file_path: z.string().describe('The absolute path to the file to read'),

    limit: z.number().optional().describe('Number of lines to read'),

    // 1. 扩展路径
    const absolutePath = expandPath(file_path)
    
    // 2. 检查设备文件 (安全)
    if (BLOCKED_DEVICE_PATHS.has(absolutePath)) {
      throw new Error(`Cannot read device file: ${absolutePath}`)
    }
    
    // 3. 检测文件类型
    if (isPDFExtension(absolutePath)) {
      // PDF 处理
      const pdfContent = await readPDF(absolutePath, pages)
      return { data: { content: pdfContent, format: 'pdf' } }
    }
    
    if (isImageFile(absolutePath)) {
      // 图像处理
      const imageBuffer = await readFileAsync(absolutePath)
      const resized = await maybeResizeAndDownsampleImageBuffer(imageBuffer)
      return { data: { content: resized, format: 'image' } }
    }
    
    // 4. 普通文本文件
    const content = await readFileInRange(absolutePath, offset, limit)
    return { data: { content, format: 'text' } }
  },
  
  // 并发安全
  isConcurrencySafe: () => true,
  
  // 只读
  isReadOnly: () => true,
  
  // 搜索/读命令
  isSearchOrReadCommand: () => ({ isSearch: false, isRead: true }),
})
```

**关键特性**:

1. **多格式支持**: 文本、PDF、图像、Jupyter Notebook
2. **分页读取**: offset/limit 支持大文件
3. **安全防护**: 阻止读取设备文件
4. **永不持久化**: `maxResultSizeChars: Infinity`

```typescript
export const FileEditTool = buildTool({
  name: FILE_EDIT_TOOL_NAME,
  maxResultSizeChars: 100_000,
  
  inputSchema: lazySchema(() => z.strictObject({
    file_path: z.string().describe('The absolute path to the file to modify'),
    old_string: z.string().describe('The text to replace'),
    new_string: z.string().describe('The text to replace it with'),
    replace_all: z.boolean().optional().describe('Replace all occurrences'),
  })),
  
  async call({ file_path, old_string, new_string, replace_all }, context, ...) {
    // 1. 读取原文件
    const originalContent = await readFileAsync(file_path, 'utf-8')
    
    // 2. 查找匹配
    const actualOldString = findActualString(originalContent, old_string)

      }
      newContent = originalContent.replace(old_string, new_string)
    }
    
    // 4. 写入文件
    await writeTextContent(file_path, newContent)
    
    // 5. 通知 VS Code
    notifyVscodeFileUpdated(file_path)
    
    return { data: { success: true, filePath: file_path } }
  },
  
  // 非并发安全
  isConcurrencySafe: () => false,
  
  // 非只读
  isReadOnly: () => false,
  
  // 权限检查
```

## 6. 权限检查机制

### 6.1 权限检查流程

```
工具调用请求
      ↓
┌─────────────────────────────────────┐
│ 1. validateInput() (可选)           │
│    - 验证输入有效性                  │
│    - 文件是否存在等                  │
└─────────────────────────────────────┘
      ↓ 通过
┌─────────────────────────────────────┐
│ 2. checkPermissions()               │
│    - 返回 allow/deny/ask            │
│    - 可修改 input                   │
└─────────────────────────────────────┘
      ↓
┌─────────┬─────────┬─────────┐
│ allow   │ ask     │ deny    │
↓         ↓         ↓
执行工具   请求用户   拒绝执行
```

### 6.2 PermissionResult 类型

```typescript
type PermissionResult = 
  | { behavior: 'allow'; updatedInput: T }        // 允许
  | { behavior: 'deny'; updatedInput: T; message?: string }  // 拒绝
  | { behavior: 'ask'; updatedInput: T; message?: string }   // 询问用户
```

### 6.3 权限规则类型

```typescript
type ToolPermissionContext = {
  mode: PermissionMode  // default, accept-edits, plan, auto, bypass
  
  // 工作目录
  additionalWorkingDirectories: Map<string, AdditionalWorkingDirectory>
  
  // 规则 (按来源分组)
  alwaysAllowRules: ToolPermissionRulesBySource  // 总是允许
  alwaysDenyRules: ToolPermissionRulesBySource   // 总是拒绝
  alwaysAskRules: ToolPermissionRulesBySource    // 总是询问
  
  // 特殊标志
  isBypassPermissionsModeAvailable: boolean
  isAutoModeAvailable?: boolean
  strippedDangerousRules?: ToolPermissionRulesBySource
  shouldAvoidPermissionPrompts?: boolean  // 后台代理使用
}
```

### 6.4 权限规则示例


## 10. 设计模式与最佳实践

### 10.1 设计模式总结

**1. 工厂模式**

```typescript
// buildTool 工厂函数
const MyTool = buildTool({
  name: 'MyTool',
  // 只需定义必要的方法
  call: async (input, context) => { ... },
  // 其他方法使用安全默认值
})
```

**2. 策略模式**

```typescript
// 不同工具的权限检查策略
checkPermissions: async (input, context) => {
  // 工具特定策略
  if (isDangerous(input)) {
    return { behavior: 'ask', ... }
  }
  return { behavior: 'allow', ... }
}
```

**3. 模板方法模式**

```typescript
// 工具执行模板
async function executeTool(tool, input, context) {
  // 1. 验证
  if (tool.validateInput) {
    await tool.validateInput(input, context)
  }
  
  // 2. 权限
  const permission = await tool.checkPermissions(input, context)
  if (permission.behavior !== 'allow') {
    return handlePermissionResult(permission)
  }
  
  // 3. 执行
  return tool.call(input, context, ...)
}
```

### 10.2 创建新工具的最佳实践

```typescript
// 1. 使用 lazySchema 延迟 schema 创建
```
